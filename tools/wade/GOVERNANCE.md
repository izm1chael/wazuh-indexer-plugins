# WADE identity and governance reference contracts
Tracks WADE-03 and WADE-06. Run all reference suites with `sh tools/wade/test-analytics.sh`.

EntityResolver resolves trusted, tenant-scoped, typed and namespaced alias bindings using half-open validity intervals and independent knowledge-availability cutoff. IP-only identities never resolve; aliases with multiple surviving canonical IDs remain ambiguous. Provenance is retained and deduplicated. This is not a directory integration or normalization service; canonical ID allocation, authoritative provider identity, temporal corrections and tenant checks belong to the production adapter. Binding availability must reflect real observation time, not backfill assumptions.

RuleLifecycle demonstrates a digest-bound DRAFT → VALIDATED → SHADOW → APPROVED → ACTIVE → RETIRED transition policy, with independent approval, expected revision and explicit production enablement. These are pure transitions, not a persisted authorization boundary. The adapter must verify actor, tenant and action-specific permission; verify receipt type, authenticity, corpus, rule digest, freshness, independence and approval record; enforce atomic revision and single-active-version constraints; audit every transition and retain rollback history. The current Evidence record is deliberately a placeholder for those verified attestations and cannot authorize live deployment. No actual rule can be activated by this standalone module.
