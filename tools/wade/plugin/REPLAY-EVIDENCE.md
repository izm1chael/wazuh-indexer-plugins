# Durable replay and shadow evidence

IndexReplayEvidence implements TemporalPromotion.Evidence using a scoped document backend. Capture runs actual PairedTemporalReplay, not imported outcomes. It persists report payload, attestation reference and capture time by kind/receipt, checks canonical roundtrip, supports create-only idempotent capture and CAS revocation. Promotion requires distinct attestation references and disjoint case IDs, exact paired revisions, fresh unrevoked evidence and a conservative shadow quality gate with operator minimum sample sizes. The authority must verify that attestation binds exact cohort, labels, report, actual live shadow period and scope, and that different case IDs do not disguise overlapping underlying telemetry. No automatic live shadow collection is provided. Checksums are integrity checks not signatures. Revocation races across the evidence and promotion documents and active rule revocation require native handling. No direct public mutation API. The native client allowlist includes a new unregistered strict mapping; uncompiled.

Local verification: new Java suite 16 assertions passed, using actual synthetic WCS paired replay and a simulated CAS backend. Prior reference suites not yet rerun. No actual native cluster contacted.
