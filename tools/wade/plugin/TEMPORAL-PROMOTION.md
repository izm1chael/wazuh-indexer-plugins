# Independent promotion gate

TemporalPromotion integrates the paired replay report into an independently approved, explicitly activated single active pointer per tenant/rule. The trusted definitions port resolves immutable versions and author. The trusted evidence port must independently verify a stored replay, validation and shadow receipt and recheck current evidence at activation. The gate enforces operator-configured minimum labelled cohorts, strictly improved benign false-positive count, no unknown labelled cases, no malicious regressions and no protected-case failures. The candidate author cannot approve or activate. Approval expires; explicit withdrawal is possible. Compare-and-set requires expected sequence. Baseline is comparison only until an independently approved challenger is explicitly activated. The same gate implements TemporalAdmission.Approved, rejecting inactive, mismatched and disabled policies. This is not an HTTP handler: WindowService's separate authenticated authority must enforce execution permissions; resolve has no actor input. Shadow is supplied by a trusted evidence port, not implemented by this class. State store and evidence authority are injected, not a deployed registry. Last audit digest is not a durable immutable audit history; retention, rollback, deactivation/drain, live shadow collection, native approval/evidence authority, receipt persistence and actual runtime wiring remain outstanding. Do not activate before those requirements and cluster qualification.
