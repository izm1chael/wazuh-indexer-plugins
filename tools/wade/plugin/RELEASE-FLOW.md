# Integrated temporal detection release flow

IndexTemporalRegistry implements scoped immutable temporal revisions and promotion state in one bounded CAS document (max 32 revisions, 256 KiB raw payload). An existing version cannot be mutated, registration cannot activate a baseline, and the active pointer cannot reference an unknown revision. SHA-256 and canonical roundtrip checks detect corrupt payloads; they are not signatures or authorization. The unregistered strict mapping is wade-v1-temporal-registry; the native client candidate permits only exact GET/create/CAS for that index. No index bootstrap or actual native client compilation.

TemporalReleaseFlowTests exercises actual paired replay of two rule versions on shared synthetic WCS telemetry; imports the report into TemporalPromotion using fixture evidence/identity authorities; persists the active pointer; provisions a job; evaluates and stages a finding via TemporalAdmission and WindowService; injects a lost publication acknowledgement; expires and reacquires the lease; recovers exactly one publication and advances the durable-protocol checkpoint. Uses one in-memory backend emulating document CAS, not a live cluster. Authority, shadow receipt and source completeness are fixtures; do not treat those as native security or shadow validation. The fixture can emit real generated cohort JSON using --cohort. The committed Dashboard model accepted that actual Java output locally, independently calculated one reduced benign false positive with no malicious regressions, and marked it review candidate (not approval). No native OSD mount.

Local test evidence: ten related Java suites, 173 assertions passed, including 75 new assertions in this pass (12 replay, 15 job runner, 11 job document, 21 promotion, 16 release flow). All new tested Java blobs verified against GitHub. The earlier complete reference suites and native build were not run. Remaining engineering: native scoped identity/permissions, durable replay and shadow receipt authority, source snapshots, job scheduler registration, fencing at the window-write boundary, immutable promotion audit history, safe rollback/deactivation and outbox drain, native persistent risk/UEBA/graph, actual Dashboard APIs and incident consumption. All production gates open.
