# Native OpenSearch client candidate (uncompiled)

OpenSearchWindowBackend implements the Java IndexWindowStore.Backend interface using a supplied org.opensearch.transport.client.Client. It is not registered by WadePlugin. It constrains operations to the two exact WADE index names and SHA-256 document IDs, reads real-time, creates immutable documents, and replaces only reconciliation state with sequence/primary-term conditions. It requests all active shards and wait-for refresh and requires successful acknowledgements from all reported shards. A verified version conflict returns false; other exceptions, ambiguous writes and unqualified acknowledgements propagate. No automatic retries, credentials, index provisioning or context stashing/elevation. The supplied worker-context guard and client must come from a trusted native adapter; no actual role or principal enforcement is implemented here. Blocking calls must run on a bounded dedicated worker; the timeout does not prove cancellation or durability. Pre-provision exact concrete indexes, deny automatic index creation and alias substitution, and qualify translog durability, refresh, replica and failover behavior. Do not grant the plugin broad index permissions.
