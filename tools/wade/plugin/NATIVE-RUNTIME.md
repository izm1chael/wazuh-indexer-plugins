# Native temporal integration handoff

NativeTemporalRuntime composes the uncompiled native OpenSearch reader and document client with the actual tested temporal registry, paired replay, promotion, admission, window reconciliation, job cursor and scheduler tick. It is intentionally not registered by WadePlugin. Its default readOnly settings prohibit writes and active resolution. Explicit settings are required for writes and activation. The caller must supply an authenticated scope-restricted Client, actual worker context and permission checks, source inventory/identity/availability authority, verified label provenance and a durable evidence authority; these interfaces must not be wired to permissive callbacks outside a disposable fixture. No actual native scheduler registration, endpoint, role definition or index installation. Source acquisition and document backend remain uncompiled against RC2. Do not install or activate on an existing SIEM.
