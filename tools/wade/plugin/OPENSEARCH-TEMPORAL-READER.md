# Native bounded WCS reader candidate

OpenSearchTemporalReader is an unregistered Java implementation of TemporalAdmission.Reader using a supplied scoped OpenSearch Client. The query is limited to an exact concrete backing index, exact agent ID and the event-time lookback; only the required WCS fields are fetched. A single bounded result page with exact hit count is intentional: over-cap input is incomplete, not silently truncated. It rejects timed out/partial/early terminated searches, mismatched shard index UUIDs, missing/malformed timestamps or unsupported field types. No arbitrary DSL or implicit privilege escalation. The maximum query size is 10,000; greater total hits are withheld. Blocking calls must run on a bounded dedicated worker.

The trusted IdentityFence MUST actually establish concrete UUID, read stability, valid tenant/agent scope, source-schema and source-watermark authority; it is called before and after the read, but those calls alone do not create a consistent multi-index snapshot. Use no production activation until verified. The pinned RC2 source demonstrates SearchRequest/SearchSourceBuilder, termQuery, trackTotalHits, SearchHit.getSourceAsMap in plugins/setup/src/main/java/com/wazuh/setup/index/AiAssistantSessionsIndex.java and plugins/content-manager/src/main/java/com/wazuh/contentmanager/cti/catalog/index/ContentIndex.java. Remaining native signatures, shard-target UUID access, total-hits relation, date formats and actual WCS mapping must be compiled/validated against pinned artifacts. Native class uncompiled in this environment; no cluster test. For mutable sources use a qualified consistent snapshot/PIT or refuse complete evaluation. Missing event.ingested must never be substituted with event time. Numeric event codes are not coerced; unsupported types withhold. Evidence source digest reverse lookup is outstanding. No actual scheduler, rule authorization, source authority or incident integration.
